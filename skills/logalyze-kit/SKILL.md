# 智能监管（观象）应用接入

在 dsh-repo「代码仓库 → 仓库」中添加仓库并打开「日志分析」（如需合并请求自动评审可同时打开「MR 自动评审」），选择需要读取的功能分支（留空使用基线分支）。仓库清单、权限、拉取和镜像目录由 dsh-repo 管理。

在智能监管「应用仓库」中填写描述和触发别名。别名用单行输入，按 Enter 或点「添加」生成可删除标签，可用中文名称、简称和平台原始 component_code；遇到重复或歧义时按提示修正，不猜选仓库。

不需要创建 `.agents/logalyze.yaml` 或指定分析 SKILL。已有 manifest 的可用描述与别名首次读取时迁移到智能监管设置，之后在面板修改；仓库里的旧文件和知识内容保留。

DSH 从代码快照的 `.dsh/skills/`、`.agents/skills/` 以及宿主配置的目录发现 SKILL。分析者查看描述后按需加载，没有适用 SKILL 就直接读日志与代码。只读路径权限和 SKILL 发现是两项准备工作，快照须在所有读取结束后释放。

日志版本与当前功能分支提交分别记录；不要把分支最新提交称为日志对应版本。解压与报告写入任务工作目录，代码快照只读。

本接入指南不创建初版 SKILL；初版 SKILL 和案例沉淀由后续知识改进功能处理。
